# Election Ballots Dashboard

Manages proofing election ballots

---

## Overview

The Election Ballots Dashboard 2.0 is a simple application for managing the proofing process in the creation of election ballots for the 93 electoral districts of British Columbia.

---

## Features

The application facilitates uploading the ballot extract files containing the candidate details, uploading the ballot proof PDF files and the approval or rejection of each electoral district's ballot proofs.

---

## Usage

It is available for use in By-elections and General Elections.
